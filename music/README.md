# Music assets — THPT Quang Trung 30 năm

Upload the three MP3 files for the anniversary video into this `music/` folder.

## Expected filenames

1. `01-mong-uoc-ky-niem-xua.mp3` — **Mong ước kỷ niệm xưa** (Part I)
2. `02-nhu-ngay-hom-qua.mp3` — **Như ngày hôm qua** (Part II)
3. `03-phep-mau-diep-khuc.mp3` — **Phép Mầu**, selected chorus section (Part III)

## Upload instructions

1. Open the repository on GitHub.
2. Open the `music/` folder.
3. Choose **Add file → Upload files**.
4. Select the MP3 files from your computer and commit the upload.

If the chorus of *Phép Mầu* has not been cut into its own file yet, you can upload the full track with the filename above for now and note the intended chorus start/end times separately.

## Copyright and privacy

Only upload audio you have the right to store and distribute in this repository. This repository is currently public, so any committed audio files may be downloadable by anyone. If you do not have permission to distribute the recordings publicly, keep the audio out of this public repository and upload it directly to your video editor instead.

This README is only an upload guide; it does not contain audio files.
